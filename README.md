# Multi-Sector Energy Consumption Forecasting (Smart Grid)

This project forecasts energy consumption for:
- Residential sector
- Commercial sector
- Industrial sector

Using LSTM based deep learning models and provides a FastAPI + Dashboard system
to forecast next 24/48 hours energy demand.

## Project Structure

- Data preprocessing & feature engineering
- LSTM model training per sector
- Model evaluation
- FastAPI backend to serve predictions
- Web dashboard for visualization

## How to Run

1. Install requirements
2. Run FastAPI server
3. Open dashboard
